Developer bootstrap

Create the developer account

The developer is the top-level system role. It owns backups, officer lifecycles, election deletion and access-code issuance — and it is never grantable through access codes. It is gated by a dedicated developer key for this machine.

The developer channel is private. Set up the developer account with a one-time key issued from the license server (Developer console → License server → Issue developer key).
