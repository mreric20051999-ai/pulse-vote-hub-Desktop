Combine exported election files from every polling location. Duplicate voters are detected and resolved so no ballot counts twice.

Each location exports the election as JSON (Administration → Backup & export → Export election JSON). Pick those files here; the tool combines the voter rolls, flags any voter registered or voted at more than one location, and lets you resolve each before tallying.
